🚀 Easy_PeakParser
Easy_PeakParser는 독립적으로 측정된 MFC(질량유량제어기) 유량 제어 로그와 분광기 피크(Peak) 파장 데이터를 시간(Time) 기반으로 완벽하게 동기화하고, 분석에 최적화된 엑셀 파일로 자동 가공해 주는 강력한 올인원(All-in-One) 데이터 전처리 툴입니다.

🎯 개발 동기 (Motivation)
반도체 장비 제어 및 광학 실험 과정에서는 매초 단위로 쏟아지는 방대한 유량 로그와 분광 데이터를 얻게 됩니다.
하지만 서로 다른 장비에서 기록된 수백, 수천 줄의 데이터를 엑셀에 띄워두고 일일이 시간을 대조해가며 유량이 변경된 시점을 찾고 특정 구간에 색을 칠하는 수작업은 엄청난 시간 낭비이자 연구자의 피로도를 극대화하는 '지옥'과도 같은 과정입니다.
연구자는 단순 반복 작업이 아닌 '데이터 분석'에 집중해야 합니다. 이 프로그램은 클릭 한 번으로 수 시간 분량의 노가다를 단 몇 초 만에 해결하기 위해 개발되었습니다.

💡 주요 용도 (Purpose)
이기종 데이터 Time-Sync 매칭: 서로 다른 포맷을 가진 MFC 유량 기록(CSV/XLSX)과 Peak 파장 기록(CSV)의 타임스탬프를 정밀하게 비교하여 동기화합니다.

스마트 데이터 필터링: 유량이 변경되기 직전의 가장 안정화된 데이터 10개(노란색)와 유량 변경 시점의 데이터 1개(빨간색)만 추출하고, 분석에 불필요한 잉여 데이터 행은 모두 깔끔하게 제거합니다.

엑셀 자동 서식 지정 (Auto-Formatting): 가스 종류, 셋포인트, 변화량(Δ)을 계산해 직관적인 헤더를 자동 생성하며, 보기 편하도록 열 너비, 셀 색상, 틀 고정(Freeze Panes)이 즉시 적용된 *.xlsx 파일로 출력합니다.

🛠️ 실행 및 사용 방법 (How to Use)
별도의 파이썬 환경 설정 없이, 제공된 실행 파일 하나만으로 즉시 사용할 수 있습니다.

1. 프로그램 실행

폴더 내에 있는 Easy_PeakParser.exe 파일을 더블 클릭하여 실행합니다.

2. 파일 추가 (Drag & Drop 지원)

[왼쪽 창] 1. MFC 유량 파일: Ar, N2 등 배경가스와 제어가스의 셋포인트가 기록된 Raw CSV 파일 또는 이미 이 프로그램으로 한 번 정리했던 엑셀 파일을 넣습니다.

[오른쪽 창] 2. 파장 기록 파일: 장비에서 추출된 Wavelength 피크 데이터 CSV 파일들을 넣습니다. (Shift 클릭이나 드래그를 통해 여러 개를 한 번에 넣고 다중 일괄 변환이 가능합니다.)

3. 옵션 설정 및 실행

하단의 '저장 설정'에서 파일명 자동 변환(yyMMddHHmm 등) 체크 여부를 확인합니다.

[Process & Save All] 버튼을 클릭하고, 결과물(엑셀 파일들)이 저장될 폴더를 지정해 줍니다.

4. 결과 확인

지정한 폴더에 [최초측정시간]_peak_[배경가스]_[유량]_[제어가스]_[최대유량].xlsx 형태로 파일이 생성됩니다.

변환이 성공적으로 완료되었는지, 혹은 시간대가 맞지 않아 실패한 파일이 있는지 팝업 리포트를 통해 직관적으로 확인할 수 있습니다.
